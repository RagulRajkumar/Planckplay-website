# Planck Play LLP — website

The company website for **Planck Play LLP**, an R&D-led engineering company.
It presents what Planck Play does: electronics and PCB design, embedded and
IoT systems, mechanical design, software, cloud and test automation, from
first research to deployment. Visitors can explore the solutions, industries
and capabilities, read about the company and careers, and send an enquiry or
an RFP.

The site is plain HTML, CSS and JavaScript. It has no framework, no build
step and no dependencies, and it makes no third-party requests: fonts, images
and code are all included in the repository.

## Run it locally

1. Get the code:

   ```bash
   git clone https://github.com/RagulRajkumar/Planckplay-website.git
   cd Planckplay-website
   ```

2. Open `index.html` in a browser (double-click it). That's all. The site
   works straight from the file, with no server and no internet connection.

**Optional: run a local server** (for example, to test on a phone on the
same Wi-Fi). Any static server works. From the project folder, run one of:

```bash
python3 -m http.server 8000
# or
npx serve .
```

Then open <http://localhost:8000> (or the address `npx serve` prints).
